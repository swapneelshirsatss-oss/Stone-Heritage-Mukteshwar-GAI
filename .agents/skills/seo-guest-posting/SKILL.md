# Off-Page SEO & Guest Posting Strategy

When publishing blog content on third-party platforms (Medium, LinkedIn, Tripoto, guest blogs), follow this strategy to maximize Domain Authority (DA) without incurring search engine duplicate content penalties.

## 1. Golden Rule: No Direct Duplicate Publishing
- **Never copy-paste exact text** from live main website articles onto third-party sites without canonical tags.
- Search engines will index either the third-party site or ignore the duplicate, diluting authority.

## 2. Hub-and-Spoke Syndication Model
- **Hub**: Primary website article URL (e.g. `https://thestoneheritage.in/blog/...`).
- **Spokes**: External platforms linking back to the Hub with contextual anchor text.

## 3. Platform Execution Rules
- **Medium.com**: Use Medium's "Import Story" tool to automatically attach `rel="canonical"` pointing to the original website URL.
- **LinkedIn / Pulse**: Publish founder/expert thought leadership articles with 1–2 contextual backlinks to the main blog and `/stay/` room booking page.
- **Tripoto / Travelogues**: Re-write articles into itinerary style or top-tips format referencing the homestay.

## 4. Anchor Text Diversity Matrix
Maintain a natural anchor text profile across all external links:
- **Exact Keyword**: `best homestay in Mukteshwar for families`
- **Partial/LSI Keyword**: `family stone cottage in Mukteshwar`
- **Brand Anchor**: `Stone Heritage Mukteshwar`
- **URL/Generic**: `https://thestoneheritage.in/stay/`
